# Cybersecurity Essentials — Study Notes

![Defensive Security](https://img.shields.io/badge/Defensive%20Security-informational) ![SOC](https://img.shields.io/badge/SOC-informational)

Structured notes for the **Cybersecurity Essentials** course of a SOC-track Cybersecurity Diploma. They cover the defensive side of security end to end: identity and access, Active Directory, network defense, endpoint and mobile security, data loss prevention, ransomware resilience, and the frameworks SOC teams use to describe attacks.

> 🌐 **Language:** explanations are written in Arabic (Egyptian dialect) with all technical terms and commands kept in English.

## What's Covered

- Security frameworks: MITRE ATT&CK, Cyber Kill Chain, Unified Kill Chain, NIST CSF, Pyramid of Pain, Defense in Depth
- Log analysis and digital forensics: web server, network, and authentication logs, impossible-travel and VPN detection
- Active Directory core concepts, Group Policy, and Windows authentication hashes (LM, NTLM, NTLMv2)
- Zero Trust, IAM, PAM, and access control models
- Network security foundations: secure topology design, VLANs, router and switch attacks
- DLP operations and SIEM integration, ransomware (LockBit case study), backup and recovery
- Password hashing, salting, peppering, cracking techniques, and SSH key authentication
